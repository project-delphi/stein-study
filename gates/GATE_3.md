## Decisions
- **No hand-typed numbers.**
  - Numbers enter the text through `metadata-files` plus `{{< meta >}}`, and tables through `{{< include >}}`.
  - Neither document runs Python at render time.
  - Design constants (the d grid, seeds, steps, k = 6, batch size) and dataset facts (480,000 images, factor sizes)
    are typed, because they are inputs rather than results.
  - Run times in REPRODUCE.md are quoted from the compute logs and GATE_2.
- **Typst over LaTeX.** No LaTeX is needed, and typst 0.15 embeds PDF figures directly.
- **Author line is "Ravi Kalia",** the git user and study owner. The reproducibility statement discloses that an AI
  agent (Claude) ran the experiments and drafted the text. The owner may want to change the author line.
- **Blog written by a general-purpose sub-agent** from a written brief; I reviewed and edited it:
  - merged two adjacent lists that pandoc would have joined;
  - "camera orientation" → "orientation";
  - "synthetic … 64×64" → "rendered … 32×32";
  - checked that the probe-standardisation claim matches `stein/metrics.py`.
- **Small code changes, with defaults and run hashes unchanged** (pytest: 28 passed afterwards):
  - an opt-in `STEIN_RUNS` env var for the run-cache directory (`train.run`, `sweep`);
  - a `grids.heldout_h5()` grid (its 25 hashes equal the held-out H5 hashes);
  - a new `stein/report.py` and `tools/repro_h5.py`.
- **`notes/_work/build_bib.py`** now braces bare BibTeX month macros (`month=July` → `month={July}`), because typst's
  BibLaTeX parser rejected them. I regenerated `paper/refs.bib`; the diff is only those 5 month fields.
- **`.gitignore`** gains `!blog/data/`. The bare `data/` rule hid the blog's input files, so the runner would not
  have committed them.
- **`pypdf` added** for the page count, and `requirements.txt` re-pinned (`uv pip freeze`; the only change is
  pypdf 7.0.0).
- **Transpose written as `^{\mathsf{T}}`.** Pandoc's typst writer mangles `^\top` followed by a symbol.
- **Discussion framing.** The "spare dimensions are filled with nuisance" account in the Discussion is labelled an
  interpretation, not a tested claim.
